# Описание функций

## circle.py

### `area(r)`

```python
def area(r):
    '''на вход функции подается радиус круга r, выводит площадь'''
    return math.pi * r * r
```

**Параметры:**
- `r: int | float` — радиус круга

**Возвращаемое значение:** `float` — площадь круга, `π · r²`

**Сложность:** константная, O(1)

**Пример:**
```
area(10)   -> 314.1592653589793
area(5)    -> 78.53981633974483
area(2.5)  -> 19.634954084936208
```

### `perimeter(r)`

```python
def perimeter(r):
    '''на вход функции подается радиус круга r, выводит периметр'''
    return 2 * math.pi * r
```

**Параметры:**
- `r: int | float` — радиус круга

**Возвращаемое значение:** `float` — длина окружности, `2 · π · r`

**Сложность:** константная, O(1)

**Пример:**
```
perimeter(10)   -> 62.83185307179586
perimeter(5)    -> 31.41592653589793
perimeter(2.5)  -> 15.707963267948966
```

## rectangle.py

### `area(a, b)`

```python
def area(a, b):
    '''на вход функции подаются стороны прямоугольника a, b, выводит площадь'''
    return a * b
```

**Параметры:**
- `a: int | float` — первая сторона прямоугольника
- `b: int | float` — вторая сторона прямоугольника

**Возвращаемое значение:** `int | float` — площадь прямоугольника, `a · b`
(тип зависит от типов аргументов: `int * int -> int`, иначе `float`)

**Сложность:** константная, O(1)

**Пример:**
```
area(10, 5)   -> 50          # int
area(13, 2)   -> 26          # int
area(2.5, 4)  -> 10.0        # float
```

### `perimeter(a, b)`

```python
def perimeter(a, b):
    '''на вход функции подаются стороны прямоугольника a, b, выводит периметр'''
    return 2 * (a + b)
```

**Параметры:**
- `a: int | float` — первая сторона прямоугольника
- `b: int | float` — вторая сторона прямоугольника

**Возвращаемое значение:** `int | float` — периметр прямоугольника, `2 · (a + b)`

**Сложность:** константная, O(1)

**Пример:**
```
perimeter(13, 2)   -> 30       # int
perimeter(10, 5)   -> 30       # int
perimeter(2.5, 4)  -> 13.0     # float
```

## triangle.py

### `area(a, h)`

```python
def area(a, h):
    '''на вход функции подается сторона a и высота треугольника h,
    опущенная к ней, выводит площадь'''
    return (a * h) / 2
```

**Параметры:**
- `a: int | float` — сторона треугольника
- `h: int | float` — высота, опущенная на сторону `a`

**Возвращаемое значение:** `float` — площадь треугольника, `(a · h) / 2`
(всегда `float` из-за оператора деления `/`)

**Сложность:** константная, O(1)

**Пример:**
```
area(10, 5)   -> 25.0     # float
area(5, 20)   -> 50.0     # float
area(3, 4)    -> 6.0      # float
```

### `perimeter(a, b, c)`

```python
def perimeter(a, b, c):
    '''на вход функции подаются стороны a, b, c, выводит периметр'''
    return a + b + c
```

**Параметры:**
- `a: int | float` — первая сторона треугольника
- `b: int | float` — вторая сторона треугольника
- `c: int | float` — третья сторона треугольника

**Возвращаемое значение:** `int | float` — периметр треугольника, `a + b + c`

**Сложность:** константная, O(1)

**Пример:**
```
perimeter(3, 4, 5)     -> 12        # int
perimeter(12, 5, 13)   -> 30        # int
perimeter(1.5, 2, 2.5) -> 6.0       # float
```
